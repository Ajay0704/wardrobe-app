# 360° Try-on Spin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On "See it on you", let a saved look with a saved try-on render be made into a 6-second 360° video spin that the customer can drag to turn, saved to the look.

**Architecture:**
- A new route `/api/tryon-spin` downloads the caller's own render, asks `gemini-omni-1.1-flash` for one full turn (front render as the first and last frame), stores the MP4 in `renders-private` and returns its path.
- The path is saved on `Outfit.spinPath`.
- On the device, the MP4 is played once to pull out 72 frames as small JPEGs, paced by frame-to-frame difference, and drawn on a canvas turntable lifted from the prototype at `src/components/proto/TryOn360Preview.tsx`.

**Spec:** `docs/superpowers/specs/2026-10-24-tryon-360-spin-design.md` — read it first.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before writing route code), React 19, zustand store (`src/lib/store.ts`), Supabase Storage (`renders-private` bucket), Gemini Interactions API, Capacitor iOS shell (WKWebView). Tests are plain `node --experimental-strip-types` scripts through `scripts/reshook.mjs`.

## Global Constraints

- Model `gemini-omni-1.1-flash`. Endpoint `https://generativelanguage.googleapis.com/v1beta/interactions`, header `x-goog-api-key`.
- Request always carries `duration: "6s"`, `aspect_ratio: "9:16"`, `resolution: "720p"` and `task: "image_to_video"`. A missing duration can bill 10 s.
- Stored values are bucket PATHS (`<userId>/<uuid>.mp4`). Never a signed URL, never inline data, one slash only (`isRenderPath`).
- Route: `maxDuration = 60`, provider timeout `50_000` ms.
- Rate limit: tier `spin` with `windowMs: 24 * 60 * 60_000`, `anon: 0`, `user: 5`.
- Device frames: `SPIN_FRAMES = 72` at 480×640 JPEG quality 0.82. Use `onload`, never `img.decode()` (it hangs in the desktop app's browser pane).
- Nothing generates on mount, on scene change or on garment change. Only an explicit tap on "Make it 360°".
- UI is gated by `NEXT_PUBLIC_TRYON_SPIN === "1"`.
- The repo lint rule `react-hooks/set-state-in-effect`: no `setState` in an effect BODY. Use promise, interval or event callbacks. The `react-hooks/purity` rule: `Date.now()` only inside `useCallback` handlers or callbacks.
- Commit messages start `AJA-305:`. Worktree commits skip the Linear post-commit hook, so comment on AJA-305 manually at the end.

```ts
/**
 * AJA-305 — the 360° spin request, as a pure function, so the test checks the REAL body
 * the route sends (the `tryon-prompt.ts` pattern).
 *
 * Measured on the prototype (2026-10-24): this exact prompt with the front render as both
 * first and last frame produced one clean full turn on the first try — 6.0s, 144 frames,
 * 34,752 output tokens (~$0.61), 27.5s wall clock.
 */

export const SPIN_MODEL = "gemini-omni-1.1-flash";
/** Billing is per output second; always sent, because the API documents no default. */
export const SPIN_SECONDS = 6;

export const SPIN_PROMPT =
  "A full-length studio photograph of a person comes to life. The person slowly turns on the spot through ONE complete " +
  "360-degree rotation at a steady, even speed: first turning to show the camera their right side, then their back, then " +
  "their left side, and finally back to face the camera, ending exactly as in the last frame. The camera is locked off: no " +
  "camera movement, no zoom, no cuts. The same person, the same outfit, the same soft studio lighting and the same seamless " +
  "light-grey backdrop throughout. Arms stay relaxed at the sides, hands empty, feet stay in place — no walking, no posing, " +
  "no other motion. Photorealistic. No text, no music.";

type ImagePart = { type: "image"; data: string; mime_type: string };
type TextPart = { type: "text"; text: string };

export interface SpinRequestBody {
  model: typeof SPIN_MODEL;
  input: Array<ImagePart | TextPart>;
  response_format: Array<{ type: "video"; aspect_ratio: "9:16"; resolution: "720p"; duration: string }>;
  generation_config: { video_config: { task: "image_to_video" } };
}

export function buildSpinRequest(front: { data: string; mimeType: string }): SpinRequestBody {
  const frame: ImagePart = { type: "image", data: front.data, mime_type: front.mimeType };
  return {
    model: SPIN_MODEL,
    // Same image first and last: the clip ends where it starts, so the turntable loops.
    input: [frame, { ...frame }, { type: "text", text: SPIN_PROMPT }],
    response_format: [{ type: "video", aspect_ratio: "9:16", resolution: "720p", duration: `${SPIN_SECONDS}s` }],
    generation_config: { video_config: { task: "image_to_video" } },
  };
}
```

```ts
/**
 * AJA-305 — turn a spin clip's frames into angles.
 *
 * The model doesn't turn evenly: the test clip eased out of the front, lingered ~1s on the
 * back, then hurried round. Mapping a drag to TIME would make the same swipe turn a
 * different amount depending on where you are. Consecutive-frame difference tracks turning
 * speed, so the cumulative difference, scaled to 360°, is a good angle for each frame.
 */

/** A held frame still advances by this share of the mean step, so angles strictly increase. */
const FLOOR_SHARE = 0.05;

/**
 * `diffs[i]` is how different frame i is from frame i-1 (`diffs[0]` is ignored).
 * Returns one angle per frame: 0 for the first, 360 for the last.
 */
export function turnAngles(diffs: number[]): number[] {
  if (diffs.length === 0) return [];
  if (diffs.length === 1) return [0];
  const steps = diffs.slice(1).map((d) => (Number.isFinite(d) && d > 0 ? d : 0));
  const mean = steps.reduce((a, b) => a + b, 0) / steps.length;
  // All-identical frames (mean 0) degrade to an even spread rather than dividing by zero.
  const floor = mean > 0 ? mean * FLOOR_SHARE : 1;
  const sized = steps.map((d) => Math.max(floor, d));
  const total = sized.reduce((a, b) => a + b, 0);
  const out = [0];
  let acc = 0;
  for (const d of sized) {
    acc += d;
    out.push((acc / total) * 360);
  }
  return out;
}

/** Index of the frame nearest `deg` (any angle; wrapped into 0-360). */
export function frameForAngle(angles: number[], deg: number): number {
  if (angles.length === 0) return 0;
  const d = ((deg % 360) + 360) % 360;
  let lo = 0;
  let hi = angles.length - 1;
  while (lo < hi) {
    const mid = (lo + hi) >> 1;
    if (angles[mid] < d) lo = mid + 1;
    else hi = mid;
  }
  if (lo > 0 && d - angles[lo - 1] < angles[lo] - d) return lo - 1;
  return lo;
}
```

```ts
/**
 * AJA-305 — turn a spin MP4 into frames the turntable can draw, on the device.
 *
 * WHY NOT SEEK THE VIDEO WHILE DRAGGING: the model's MP4 has ONE keyframe in 144 frames, so
 * every seek decodes from the start — it stutters, worst in WKWebView. Instead the clip is
 * played once (muted, 2×) and frames are captured as they're presented, which decodes it
 * front to back exactly once.
 *
 * WHY JPEG <img>s, NOT ImageBitmaps: 72 decoded 480×640 bitmaps hold ~88MB, a real risk in
 * WKWebView. ~15KB JPEGs are decoded on demand by the browser.
 *
 * WHY A BLOB URL: drawing a cross-origin <video> taints the canvas and `toBlob` throws
 * SecurityError. Fetching to a Blob first makes it same-origin, and gives download progress.
 *
 * `onload`, never `img.decode()` — decode() never settles in the desktop app's browser pane.
 */
import { turnAngles } from "./spin-pacing";

export const SPIN_FRAMES = 72;
const OUT_W = 480;
const OUT_H = 640;
const THUMB_W = 24;
const THUMB_H = 32;

export interface SpinFrames {
  images: HTMLImageElement[];
  /** One per image, 0 → 360, from `turnAngles`. */
  angles: number[];
  /** Revoke every blob URL. Call when the screen closes. */
  release(): void;
}

async function download(url: string, onProgress: (f: number) => void): Promise<Blob> {
  const res = await fetch(url);
  if (!res.ok || !res.body) throw new Error("Couldn't load the spin.");
  const total = Number(res.headers.get("content-length")) || 0;
  const reader = res.body.getReader();
  const chunks: Uint8Array[] = [];
  let got = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    chunks.push(value);
    got += value.length;
    if (total) onProgress(Math.min(1, got / total));
  }
  return new Blob(chunks as BlobPart[], { type: "video/mp4" });
}

const once = (el: HTMLElement, event: string) =>
  new Promise<void>((resolve, reject) => {
    el.addEventListener(event, () => resolve(), { once: true });
    el.addEventListener("error", () => reject(new Error("Couldn't load the spin.")), { once: true });
  });

/** Fit a 9:16 frame into 3:4 by stretching its outermost columns outward. Bars and a
 *  blurred fill both showed a seam in the prototype; a smear doesn't. */
function fit(ctx: CanvasRenderingContext2D, video: HTMLVideoElement) {
  const w = Math.round((OUT_H * video.videoWidth) / video.videoHeight);
  const x0 = Math.round((OUT_W - w) / 2);
  ctx.drawImage(video, x0, 0, w, OUT_H);
  if (x0 > 0) {
    ctx.drawImage(ctx.canvas, x0, 0, 1, OUT_H, 0, 0, x0, OUT_H);
    ctx.drawImage(ctx.canvas, x0 + w - 1, 0, 1, OUT_H, x0 + w, 0, OUT_W - x0 - w, OUT_H);
  }
}

function meanAbsDiff(a: Uint8ClampedArray, b: Uint8ClampedArray): number {
  let sum = 0;
  for (let i = 0; i < a.length; i += 4) {
    sum += Math.abs(a[i] - b[i]) + Math.abs(a[i + 1] - b[i + 1]) + Math.abs(a[i + 2] - b[i + 2]);
  }
  return sum / (a.length / 4);
}

const loadImage = (src: string) =>
  new Promise<HTMLImageElement>((resolve, reject) => {
    const img = new Image();
    img.onload = () => resolve(img);
    img.onerror = () => reject(new Error("Couldn't load the spin."));
    img.src = src;
  });

export async function loadSpinFrames(
  url: string,
  onProgress: (fraction: number) => void,
): Promise<SpinFrames> {
  const blob = await download(url, (f) => onProgress(f * 0.5));
  const videoUrl = URL.createObjectURL(blob);
  const frameUrls: string[] = [];
  const release = () => {
    URL.revokeObjectURL(videoUrl);
    frameUrls.forEach((u) => URL.revokeObjectURL(u));
  };

  try {
    const video = document.createElement("video");
    video.muted = true;
    video.playsInline = true;
    video.preload = "auto";
    video.src = videoUrl;
    await once(video, "loadeddata");

    const out = document.createElement("canvas");
    out.width = OUT_W;
    out.height = OUT_H;
    const ctx = out.getContext("2d")!;
    const thumb = document.createElement("canvas");
    thumb.width = THUMB_W;
    thumb.height = THUMB_H;
    const tctx = thumb.getContext("2d", { willReadFrequently: true })!;

    const targets = Array.from({ length: SPIN_FRAMES }, (_, i) => (i / SPIN_FRAMES) * video.duration);
    const blobs: Promise<Blob | null>[] = [];
    const diffs: number[] = [];
    let prev: Uint8ClampedArray | null = null;

    // Synchronous on purpose: `toBlob` snapshots the canvas when it's CALLED, so the next
    // frame can be drawn before this one has finished encoding.
    const capture = () => {
      fit(ctx, video);
      tctx.drawImage(out, 0, 0, THUMB_W, THUMB_H);
      const px = tctx.getImageData(0, 0, THUMB_W, THUMB_H).data;
      diffs.push(prev ? meanAbsDiff(prev, px) : 0);
      prev = px;
      blobs.push(new Promise((r) => out.toBlob(r, "image/jpeg", 0.82)));
      onProgress(0.5 + 0.45 * (blobs.length / SPIN_FRAMES));
    };

    if ("requestVideoFrameCallback" in video) {
      await new Promise<void>((resolve, reject) => {
        let next = 0;
        const onFrame = (_now: number, meta: { mediaTime: number }) => {
          while (next < targets.length && meta.mediaTime + 1 / 48 >= targets[next]) {
            capture();
            next += 1;
          }
          if (next >= targets.length) resolve();
          else video.requestVideoFrameCallback(onFrame);
        };
        video.addEventListener("ended", () => {
          while (next < targets.length) {
            capture();
            next += 1;
          }
          resolve();
        }, { once: true });
        video.requestVideoFrameCallback(onFrame);
        video.playbackRate = 2;
        video.play().catch(reject);
      });
      video.pause();
    } else {
      for (const t of targets) {
        video.currentTime = t;
        await once(video, "seeked");
        capture();
      }
    }

    const jpegs = await Promise.all(blobs);
    const images = await Promise.all(
      jpegs.map((b) => {
        if (!b) throw new Error("Couldn't load the spin.");
        const u = URL.createObjectURL(b);
        frameUrls.push(u);
        return loadImage(u);
      }),
    );
    onProgress(1);
    URL.revokeObjectURL(videoUrl); // the frames don't need the video any more
    return { images, angles: turnAngles(diffs), release };
  } catch (e) {
    release();
    throw e;
  }
}
```

```tsx
"use client";

/**
 * AJA-305 — the 360° spin turntable: drag to turn, flick to coast, arrow keys, four angle
 * tiles. Presentation only; `useSpin` owns making and loading.
 *
 * Lifted from the prototype (src/components/proto/TryOn360Preview.tsx), where the feel was
 * tuned with Ajay:
 *  - Drawn IMPERATIVELY on a canvas, never by swapping <img> src (Safari can flash a blank
 *    frame mid-drag).
 *  - Drag direction is negative: as the angle grows the body faces further to the viewer's
 *    left, so dragging left has to grow it — the body follows the finger.
 *  - No settling after a coast: every frame is a real picture, so wherever it stops is a
 *    finished view. (The photo turntable it replaced had to snap; this doesn't.)
 */

import { type KeyboardEvent, type PointerEvent, useCallback, useEffect, useRef, useState } from "react";
import { frameForAngle } from "@/lib/spin-pacing";
import type { SpinFrames } from "@/lib/spin-frames";

const DRAG_DEG_PER_PX = -0.6;
/** Coast distance ≈ vel·16/(1−FRICTION): the hardest flick goes about half a turn. */
const FRICTION = 0.92;
const STOP_BELOW = 0.01;
const MAX_VEL = 0.9;
/** A finger held still this long before lifting is a release, not a flick. */
const STILL_MS = 60;

const norm = (deg: number) => ((deg % 360) + 360) % 360;
const SECTORS = ["Front", "¾", "Side", "¾ back", "Back", "¾ back", "Side", "¾"];
const sectorName = (deg: number) => SECTORS[Math.round(norm(deg) / 45) % 8];
const TILES = [
  { label: "Front", deg: 0 },
  { label: "¾", deg: 45 },
  { label: "Side", deg: 90 },
  { label: "Back", deg: 180 },
];
function tileFor(deg: number): number {
  const d = norm(deg);
  const off = Math.min(d, 360 - d);
  return off < 22.5 ? 0 : off < 67.5 ? 1 : off < 112.5 ? 2 : 3;
}
const prefersReducedMotion = () =>
  typeof window !== "undefined" && window.matchMedia?.("(prefers-reduced-motion: reduce)").matches;

export function SpinTurntable({ frames }: { frames: SpinFrames }) {
  const [angle, setAngle] = useState(0);
  const [dragging, setDragging] = useState(false);
  const [turned, setTurned] = useState(false);
  const angleRef = useRef(0);
  const drag = useRef<{ x: number; at: number; vel: number } | null>(null);
  const raf = useRef<number | null>(null);
  const canvasRef = useRef<HTMLCanvasElement | null>(null);

  const draw = useCallback(
    (deg: number) => {
      const c = canvasRef.current;
      const img = frames.images[frameForAngle(frames.angles, deg)];
      if (!c || !img?.naturalWidth) return;
      c.getContext("2d")?.drawImage(img, 0, 0, c.width, c.height);
    },
    [frames],
  );
  const setBoth = useCallback(
    (deg: number) => {
      angleRef.current = deg;
      draw(deg);
      setAngle(deg);
    },
    [draw],
  );
  const attachCanvas = useCallback(
    (el: HTMLCanvasElement | null) => {
      canvasRef.current = el;
      if (el) draw(angleRef.current);
    },
    [draw],
  );

  useEffect(
    () => () => {
      if (raf.current !== null) cancelAnimationFrame(raf.current);
    },
    [],
  );

  const animateTo = useCallback(
    (deg: number) => {
      if (raf.current !== null) cancelAnimationFrame(raf.current);
      const target = angleRef.current + (((deg - norm(angleRef.current) + 540) % 360) - 180);
      if (prefersReducedMotion()) {
        setBoth(target);
        return;
      }
      const step = () => {
        const next = angleRef.current + (target - angleRef.current) * 0.18;
        if (Math.abs(target - next) < 0.2) {
          setBoth(target);
          raf.current = null;
          return;
        }
        setBoth(next);
        raf.current = requestAnimationFrame(step);
      };
      raf.current = requestAnimationFrame(step);
    },
    [setBoth],
  );

  const coast = useCallback(
    (startVel: number) => {
      if (raf.current !== null) cancelAnimationFrame(raf.current);
      if (prefersReducedMotion() || Math.abs(startVel) < STOP_BELOW) return;
      let vel = Math.max(-MAX_VEL, Math.min(MAX_VEL, startVel));
      let last = performance.now();
      const step = (now: number) => {
        const dt = Math.min(48, now - last);
        last = now;
        setBoth(angleRef.current + vel * dt);
        vel *= Math.pow(FRICTION, dt / 16);
        raf.current = Math.abs(vel) < STOP_BELOW ? null : requestAnimationFrame(step);
      };
      raf.current = requestAnimationFrame(step);
    },
    [setBoth],
  );

  const onPointerDown = (e: PointerEvent<HTMLDivElement>) => {
    if (raf.current !== null) cancelAnimationFrame(raf.current);
    drag.current = { x: e.clientX, at: performance.now(), vel: 0 };
    e.currentTarget.setPointerCapture(e.pointerId);
    setDragging(true);
  };
  const onPointerMove = (e: PointerEvent<HTMLDivElement>) => {
    const d = drag.current;
    if (!d) return;
```

```ts
"use client";

/**
 * AJA-305 — the 360° spin for one saved look: make it, attach it, load it.
 *
 * Kept out of TryOnView, which is already ~490 lines of its own states. Nothing here runs
 * on mount: `open()` (switching to 360°) loads an existing spin for free, and only `make()`
 * (an explicit tap) spends money — TryOnView's rule.
 *
 * Saving is automatic. The route stores the clip and this attaches it the moment it
 * returns: a $0.61 result that vanished when you left the screen would be AJA-275 again.
 */

import { useCallback, useEffect, useRef, useState } from "react";
import { loadSpinFrames, type SpinFrames } from "@/lib/spin-frames";
import { useWardrobe } from "@/lib/store";
import { deletePrivateImage, signedPrivateUrl } from "@/lib/supabase/private-storage";
import { makeSpin } from "@/lib/tryon-spin";

/** Median measured make. The bar approaches 99 asymptotically and never claims 100 early. */
const TYPICAL_MS = 28_000;
const TAU = TYPICAL_MS / 2.4;

type Status = "idle" | "making" | "loading" | "ready" | "error";

export function useSpin(outfitId?: string) {
  const authUser = useWardrobe((s) => s.authUser);
  const setOutfitSpin = useWardrobe((s) => s.setOutfitSpin);
  const renderPath = useWardrobe((s) =>
    outfitId ? s.outfits.find((o) => o.id === outfitId)?.tryOnRenderPath : undefined,
  );
  const spinPath = useWardrobe((s) =>
    outfitId ? s.outfits.find((o) => o.id === outfitId)?.spinPath : undefined,
  );

  const [status, setStatus] = useState<Status>("idle");
  const [progress, setProgress] = useState(0);
  const [frames, setFrames] = useState<SpinFrames | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [unavailable, setUnavailable] = useState(false);
  const [makingSince, setMakingSince] = useState<number | null>(null);
  const loadedFor = useRef<string | null>(null);
  const framesRef = useRef<SpinFrames | null>(null);

  const available =
    process.env.NEXT_PUBLIC_TRYON_SPIN === "1" && !!outfitId && !!renderPath && !!authUser && !unavailable;

  // The making clock. setState in the interval callback, never the effect body.
  useEffect(() => {
    if (makingSince === null) return;
    const id = window.setInterval(() => {
      setProgress(1 - Math.exp(-(Date.now() - makingSince) / TAU));
    }, 100);
    return () => window.clearInterval(id);
  }, [makingSince]);

  // Free the frame blob URLs when the screen closes or a new spin replaces them.
  useEffect(() => () => framesRef.current?.release(), []);

  const load = useCallback(async (path: string) => {
    setStatus("loading");
    setProgress(0);
    setError(null);
    try {
      const url = await signedPrivateUrl(path);
      if (!url) throw new Error("Couldn't load the spin.");
      const next = await loadSpinFrames(url, setProgress);
      framesRef.current?.release();
      framesRef.current = next;
      loadedFor.current = path;
      setFrames(next);
      setStatus("ready");
    } catch (e) {
      setError(e instanceof Error ? e.message : "Couldn't load the spin.");
      setStatus("error");
    }
  }, []);

  /** Switching to 360°: show an existing spin, free. Never generates. */
  const open = useCallback(() => {
    if (spinPath && loadedFor.current !== spinPath) void load(spinPath);
  }, [spinPath, load]);

  const make = useCallback(async () => {
    if (!outfitId || !renderPath) return;
    setStatus("making");
    setError(null);
    setProgress(0);
    setMakingSince(Date.now());
    try {
      const path = await makeSpin(renderPath);
      const previous = spinPath;
      setOutfitSpin(outfitId, path);
      if (previous && previous !== path) void deletePrivateImage(previous);
      setMakingSince(null);
      await load(path);
    } catch (e) {
      setMakingSince(null);
      const msg = e instanceof Error ? e.message : "Couldn't film this look. Try again.";
      if (/isn't configured/i.test(msg)) setUnavailable(true);
      setError(msg);
      setStatus("error");
    }
  }, [outfitId, renderPath, spinPath, setOutfitSpin, load]);

  return {
    available,
    status,
    progress,
    frames,
    error,
    hasSpin: !!spinPath,
    open,
    make: () => void make(),
  };
}
```
